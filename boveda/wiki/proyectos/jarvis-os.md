# jarvis-os

> Relacionado: [[perfil]], [[decisiones]]

## Qué es
Este asistente: Claude Code con habilidades, bóveda de Obsidian, voz local, HUD y rutinas.
Partes: PC (voz, HUD, copiloto, gestos, archivos), servidor Clouding (API y app del celular, WhatsApp, rutinas, pruebas de seguridad), app de Android ("Jarvis" siempre escuchando) y la bóveda sincronizada con Syncthing.
Se actualiza solo desde GitHub (`scripts/actualizar.sh`, registro en `logs/actualizar.log`).

## Stack
Python (voz, HUD, API del servidor), Bash, Claude Code, Node (WhatsApp), Kotlin con Vosk (Android)
